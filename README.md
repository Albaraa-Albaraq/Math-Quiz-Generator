# ➗ Math Quiz Game (C++)

A **console-based math quiz game** built in **C++**.  
The program generates random math questions based on the user’s chosen **level** and **operation type**, checks the answers, and displays a detailed final result.  

## 🔑 Features
- Choose quiz **level**: Easy, Medium, Hard, or Mix.  
- Select operation type: Addition, Subtraction, Multiplication, Division, or Mixed.  
- Answer up to **90 questions** in one quiz.  
- Automatic correction with **right/wrong feedback**.  
- Colored console output (green for correct, red for wrong).  
- Displays **final score**: number of right/wrong answers and PASS/FAIL result.  

## 🚀 How to Run
1. Compile the code with any C++ compiler (e.g., g++).  
   ```bash
   g++ main.cpp -o mathquiz
   ./mathquiz
   ```
2. Enter the number of questions (1–90).  
3. Choose quiz level and operation type.  
4. Answer the questions and check your result.
